## 📌 About This Repository

This repository documents the successful completion of a structured VLSI Design Internship focused on digital design, verification, synthesis, timing analysis, and Design-for-Testability (DFT).

The projects simulate a real-world ASIC/FPGA front-end design flow, covering:

* RTL Design and Verification
* Functional Simulation
* FPGA Synthesis
* Gate-Level Verification
* Static Timing Analysis (STA)
* Timing Closure
* Design for Testability (DFT)
* LVS/DRC Verification Concepts
