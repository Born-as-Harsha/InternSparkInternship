
# Task-4: DFT & Basic Physical Verification (LVS/DRC Concepts)

## Objective

Introduce Design for Testability (DFT) using scan chain concepts and understand Layout Versus Schematic (LVS) and Design Rule Check (DRC) verification methodologies.

## Tools Used

* Vivado 2025.2
* Verilog HDL

## Project Contents

* DFT_Design.v
* DFT_Design_tb.v
* RTL_Schematic.pdf
* DFT_Plan.md
* LVS_DRC_Report.md

## DFT Overview

The design implements a basic scan-enabled flip-flop structure. During normal operation, data is captured through the functional input. During test mode, scan data is shifted through the scan chain using the scan enable signal.

## Physical Verification Overview

The project includes conceptual understanding of:

* Design Rule Check (DRC)
* Layout Versus Schematic (LVS)
* Test Coverage
* Stuck-at Fault Detection

## Conclusion

The DFT architecture and physical verification flow were studied and documented successfully.
